# 错误特征对照手册

## 服务类错误特征

| 错误特征 | 可能根因 | 建议操作 |
| --- | --- | --- |
| context canceled 占比高 | 下游服务响应慢，请求超时被主动取消 | 查下游服务状态，联系对应团队 |
| connection refused | 目标服务实例挂了或端口不通 | 检查目标服务是否运行、端口是否监听 |
| 数据库连接池耗尽 | 慢查询过多或连接泄漏 | 查慢查询日志，检查连接释放逻辑 |

## GPU/训练类错误特征

| 错误特征 | 可能根因 | 建议操作 |
| --- | --- | --- |
| CUDA out of memory | 显存被占满，batch 过大或残留进程 | 减小 batch、清理残留进程（需确认） |
| Out of memory: Killed process | 系统内存耗尽被 OOM Killer 杀掉 | 减小 num_workers、流式读数据 |
| NCCL timeout | 某 rank 进程挂掉，其余等待超时 | 检查各节点进程与网络连通性 |
| no kernel image is available | CUDA 版本与驱动不匹配 | 按驱动版本重装对应 PyTorch |

## 使用说明

排查时先从日志/监控拿到错误特征关键词，再到本表匹配根因与建议操作。若日志无明显 error 特征，转查进程资源占用（CPU/显存/内存）。
