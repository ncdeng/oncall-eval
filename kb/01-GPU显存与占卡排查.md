# GPU 显存与占卡排查手册

## 显存占满（CUDA out of memory）

当训练或推理任务报 `CUDA out of memory` 时，说明目标卡的显存已被占满。排查顺序：

1. 用 `nvidia-smi` 查看每张卡的显存占用与对应进程 PID；
2. 按 PID 用 `ps -o user= -p <PID>` 定位占用者；
3. 若为他人残留进程（任务已结束但进程未退出），联系本人或值班群确认后再处理；
4. 确认无主的僵尸进程可清理，但清理属于高危操作，需人工确认后执行。

常见根因：batch size 过大、未使用梯度累积、上一次任务异常退出导致显存未释放。

## 显卡被独占 / 无卡可用

多人共用服务器时，常出现「明明有 8 张卡却申请不到」的情况。排查：

- `nvidia-smi` 查看每张卡的实际利用率与显存；
- 若某进程长期占卡但利用率为 0（挂着不跑），多为调试时忘记释放，需联系占用者；
- 推荐用 `CUDA_VISIBLE_DEVICES` 指定空闲卡，避免与他人冲突。

## 显存碎片与利用率低

利用率长期低于 30% 但显存占满，通常是数据加载（DataLoader）成为瓶颈，或 batch 太小。可增大 `num_workers`、开启 pin_memory、增大 batch size。
