# 账号权限与配额管理手册

## 新人开号流程

1. 导师或师兄在值班群提交申请（姓名、学号、导师、预计使用需求）；
2. 管理员创建账号，默认加入 data 组（公共数据集只读权限）；
3. 默认配额：home 50GB、`/data/users/<用户名>` 2TB；
4. 首次登录强制改密，并建议配置 SSH 密钥登录。

## sudo 与系统软件安装政策

普通用户一律无 sudo。需要系统级依赖时：

- Python 包用 conda / `pip install --user`，不需要 root；
- 系统库（如 `libgl1`、`ffmpeg`）联系管理员统一安装，或用 conda 内的对应包（`conda install -c conda-forge ffmpeg`）；
- 自行编译安装到个人目录（`./configure --prefix=$HOME/.local`）也是推荐做法。

## home 配额超限的表现与处理

home 写满后的典型症状：登录时报 `.Xauthority` 相关错误、vim 无法保存、conda 安装失败。处理：

1. `du -sh ~/.[!.]* ~/* | sort -h` 找大头；
2. 常见元凶：`~/.cache`（pip/HF 缓存）、`~/.conda/pkgs`、`~/.vscode-server`；
3. 缓存类直接清（`pip cache purge`、`conda clean -a`），数据类迁移到 `/data/users/<用户名>` 并软链接回来（目录约定见数据集与共享目录管理手册）。

## 密码与密钥管理

- 忘记密码：在值班群 @管理员 重置，需本人可验证身份；
- 禁止共享账号：多人共用同一账号会导致进程归属无法追溯，违规占卡无法定责；
- 连续 5 次密码错误锁定 10 分钟（fail2ban），换 IP 或等待解锁。

## 毕业离组账号处理

离组前一个月：数据交接（有价值数据转移给接手同学或导师指定位置）、公共区个人产物清理；账号在离组后冻结 3 个月再删除，期间数据保留但不可登录。
